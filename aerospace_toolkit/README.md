# Aerospace Toolkit

A collection of practical aerospace engineering tools and calculators for drone development, RC plane design, and academic projects.

## Contents

### 🧮 flight_calculator.py
Comprehensive aerospace calculations including:

- **Aerodynamics Calculator**
  - Dynamic pressure calculations
  - Lift and drag force computations
  - Reynolds number analysis

- **Flight Dynamics Calculator**
  - Stall speed calculations
  - Turn radius computations
  - Aircraft performance analysis

- **Drone Calculator**
  - Hover power requirements
  - Battery flight time estimation
  - Multirotor-specific calculations

## Usage

```bash
# Run the demo calculations
python3 flight_calculator.py
```
